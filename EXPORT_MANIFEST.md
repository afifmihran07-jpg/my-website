# HSS Complete Project Export Manifest

Export the project root, not only `src/` or the frontend preview output.

Required production source:

- `api/index.ts`
- `server/admin.ts`
- `server/auth.ts`
- `server/commerce.ts`
- `server/crypto.ts`
- `server/customers.ts`
- `server/db/index.ts`
- `server/db/schema.ts`
- `server/env.ts`
- `server/http.ts`
- `server/images.ts`
- `server/notifications.ts`
- `server/validation.ts`
- `drizzle/0000_initial_hss.sql`
- `drizzle.config.ts`
- `src/`
- `public/`
- `package.json`
- `package-lock.json` (must be generated by npm before final distribution)
- `tsconfig.json`
- `vite.config.ts`
- `index.html`
- `.env.example`
- `PRODUCTION_SETUP.md`

Never export:

- `.env`
- `.env.local`
- real database URLs
- API keys
- SMTP passwords
- SMS tokens
- Cloudinary secrets
- bootstrap credentials
- `node_modules/`
- `dist/`

The current Astra workspace includes every item above except `package-lock.json`. The npm package-management tool available in this workspace does not expose the generated lockfile. Generate it after downloading with `npm install --package-lock-only` before treating the distribution as complete.
